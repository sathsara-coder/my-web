# Sathsara Yoshith Portfolio + Boostora LK
Static site: HTML, CSS, vanilla JS, GSAP (CDN). No backend.
## Run
Open the folder in VS Code, right-click `index.html`, choose **Open with Live Server**.
## Edit
All content is in `js/site-data.js`: bio, CV path, profile image, projects, Boostora LK logo, Facebook, Instagram, email and testimonials. Empty fields are hidden, so no broken links appear.
Add images to `assets/portfolio/` and point `image` (or `video`) in `PROJECTS` to them.
## Notes
The contact form validates input and opens WhatsApp. If GSAP fails to load, content still shows. Reduced-motion is respected.
